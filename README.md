# 異能将棋（仮） 試作版

5五将棋（5×5のミニ将棋）の駒に特別な能力（スキル）を持たせて戦う、2人対戦の将棋ゲームです。
1台の画面を2人で交互に使って遊びます。

**遊ぶ:** https://helloeveryonekusoo.github.io/inou-shogi/

## 特徴
- 勝ち方は普通の将棋と同じで、相手の玉を詰ませたら勝ち。
- 対局前に、6種類の駒それぞれにスキルのカードを選んでデッキを作る（玉以外のコスト合計8以下）。
- 相手の駒を縦か横に挟むと「勢い」がたまり、3たまると2手続けて指せる「連続指し」が使える。
- 運の要素はなく、お互いのスキルはすべて見えている。

## ファイル
- `異能将棋.html` … ゲーム本体（HTMLファイル1つで動きます）
- `異能将棋_ルール案.md` … ルールとカード表
- `index.html` … 公開ページ用の入口
