# 異能将棋（仮）

将棋の駒に特別な能力を持たせて戦う、独自の将棋ゲームです。ブラウザで遊べます。

**遊ぶ:** https://helloeveryonekusoo.github.io/inou-shogi/

## 異能将棋 体力制（新）
- 5×6の盤で、駒は1人10枚（玉・飛・角・金2・銀2・歩3）。
- 駒ごとに体力と攻撃力があり、10枚の体力の合計がプレイヤーの体力。相手の駒を取るとダメージを与える。
- 相手の体力を0にするか、玉を詰ませたら勝ち。80手で決着しなければ、体力が多い方の勝ち。
- 属性は日・月・星。駒の能力は「取った時」「成った時」に出る。玉はリーダーで、いつも効く能力を持つ。
- 6つのリーダー（楔・記憶・指令・返し石・速攻・星血）のデッキから選んで対戦する。
- コンピュータと対戦するか、1台を2人で交互に使って遊ぶ。

## 異能将棋 試作版（v0.2）
- 5×5の盤（5五将棋）で、詰みだけで勝負する最初の試作。2人対戦。
